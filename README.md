# Bake Shop Website

This is a **static website** for a bake shop, built using *HTML*, *CSS*, and *JavaScript*. Users can browse the menu, with item descriptions and prices.

This is my **first project**, where I learned how to build a simple website as I began my web development journey.

## Features:
- View menu items with descriptions and prices  
- Navigation bar added (currently empty and still a work in progress)  
- Designed with a responsive layout for desktop

## Technologies Used:
- **HTML**  
- **CSS**  
- **JavaScript**

## Future Improvements:
- Make the layout fully responsive across all screen sizes  
- Add content to the navigation pages  
- Implement a shopping cart and payment system  
- Improve user interactivity and styling
